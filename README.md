# @webship-js/gitea-steps

Cucumber step definitions for Gitea and Forgejo, the open-source self-hosted Git forges, a pack for
[webship-js](https://github.com/webship/webship-js) (Playwright and Cucumber). One pack covers both: Forgejo is a fork
of Gitea, and CI runs every step on both. Logging in, a repository and who may open it, the issue list and one issue,
its comments, assignees, milestone and time spent, closing and reopening it, a new issue, and the milestones.

The steps, their documentation and CI come with the first release, `2.0.0`.
